# Miranti Collections

Miranti Collections is a React website built with Vite.

## Run locally

```sh
npm ci
npm run dev
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds and publishes the site on every push to `main`.

After the first successful workflow run, the site will be available at:

https://ngurahariwhrihaspati.github.io/miranti-collections/

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
